# Gears on a GL layer over TinyGL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land Gears, the first OpenGL hack, on `main` through a small GL
layer over TinyGL.

**Architecture:** A byte-identical TinyGL copy is patched at build time by a
tested Python tool into one translation unit. A GL layer in `src/glshim/`
opens TinyGL over the canvas and reroutes the calls TinyGL gets wrong. Gears
and its helpers are byte-identical copies built through `USE_GL` wrappers.

**Tech Stack:** C (PlatformIO, Unity, AddressSanitizer on the host), Python
3.13 with `uv` and pytest, TinyGL (C-Chads fork), xscreensaver 6.16 sources.

**Spec:** `docs/superpowers/specs/2026-10-09-gears-gl-design.md` (approved).
Issue #42. Spike for reference: branch `worktree-spike-tinygl`, commit
`2115083`; `git show worktree-spike-tinygl:firmware/spike_tinygl.patch` is the
authoritative list of TinyGL changes (omit its `spike_verts` and `spike_tris`
counters, which were instrumentation).

## Global Constraints

- TinyGL is the C-Chads fork at commit `36a7987` (zlib-style licence, with an
  acknowledgment clause). Copied files stay byte-identical: prove with `cmp`.
- Patches: 16-bit pixels written byte-swapped; allocations of 192 bytes or
  more go to PSRAM; `glGenLists` starts at name 1; `OP_BUFFER_MAX_SIZE` is 64;
  buffer width is not rounded down to a multiple of 4; `memset_s` renamed;
  `sqrt`, `pow`, `sin`, `cos`, `floor` map to their `f` versions; decimal
  literals get an `f` suffix.
- `USE_GL` is defined per wrapper file only. `HAVE_GL` stays undefined.
- Shared-header changes are additions, invisible without `USE_GL`.
- The board's loop task stack is 16 KB; host tests cannot prove it.
- Every new test is seen to fail for the right reason first, then
  mutation-checked: break the code it covers and watch it fail, then confirm
  with `grep` or `git diff` that the mutation applied and was restored.
- Python 3.13+, `uv`, ruff, pytest. Lint Markdown from the repo root with
  `markdownlint --config .markdownlint.json <files>`.
- Commits: verify `git branch --show-current` is `feature/42-gears-gl`, add
  named paths only, and end the message with
  `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Flashing the board is permitted for this work. Report "compiles", "host
  tests pass" and "runs on the device" separately; only Rod can confirm what
  the screen shows.
- Worktree harness: keep commands plain (no heredocs, loops, `$VAR` or `&&`
  chains with computed paths); use the worktree path with the Edit tool; run
  pio as `PLATFORMIO_CORE_DIR=<worktree>/.platformio ../.venv/bin/pio ...`
  from `firmware/`, and never `cd` through the `vendor` symlink.

## Review Focus

Failure modes the spec implies that a person would hit. Each gets a test in
the task named.

1. A GL hack stopped before its first frame (two quick presses) must not
   crash or leak. Task 8.
2. Cycling Gears in and out repeatedly must not grow memory. Task 8.
3. A failed TinyGL allocation or empty canvas must give `NULL` from
   `init_GL`, not a crash. Task 5.
4. A second `init_GL` while a context is open must replace it cleanly.
   Task 5.
5. `glDrawArrays` with no array enabled, or a count of zero, must draw
   nothing. Task 6.
